# Lockfiles

This directory stores profile-specific lockfiles generated by scripts/bootstrap_env.sh.

Generated lockfiles:
- requirements/locks/core.lock
- requirements/locks/ml.lock
- requirements/locks/full-stack.lock

Generation policy:
1. Create/activate a project virtual environment.
2. Install from requirements/profiles/<profile>.txt.
3. Freeze exact versions with `pip freeze --all`.
4. Commit lockfile updates in the same change set as dependency changes.

Do not edit lockfiles manually.
