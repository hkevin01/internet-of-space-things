# Planning Document Index

Canonical planning documents are maintained under docs to avoid status drift.

## Canonical Sources

- docs/project_plan.md: Strategic plan and phase roadmap.
- docs/project_progress_tracker.md: Current execution status and progress tracking.
- docs/plan.md: Original architecture and implementation planning narrative.
- ROADMAP.md: High-level milestone timeline.

## Consolidation Policy

1. Root-level project_plan.md and project_progress_tracker.md are redirect stubs.
2. All planning edits must be applied in docs first.
3. If references are needed from root, link to docs paths rather than copying content.
